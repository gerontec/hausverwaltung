# Hausverwaltung

Property and facility management for a residential building with 21 flats
(rental management and WEG) – PHP 8 + Bootstrap 5 + MariaDB, no build step.
UI language is German.

## Features
- **Master data:** property, houses, rentable units (flats, parking, garage), WEG units with MEA and
  sub-communities, persons (tenants, owners, service providers)
- **Rental:** leases with rent history, monthly charges (Sollstellung, pro rata), tenant accounts,
  open items, tenant list
- **Bank:** CSV import (finanzblick, Sparkasse/VR/DKB style), matching by rules / IBAN / tenant name,
  manual assignment that can create rules
- **Betriebskostenabrechnung** (BetrKV, para 556 BGB): allocation keys area / units / persons / meters /
  direct, per-house cost scopes, vacancy, advances actually paid (para 366 BGB), para 35a EStG,
  "allocatable until" (e.g. cable TV), cost types excluded per lease
- **Heizkosten:** import of the metering service's per-user results (Brunata), or own calculation
  under HeizkostenV (para 9 heating/hot water split, para 7/8, degree days para 9b, para 9a estimates,
  CO2KostAufG landlord share, para 6b information)
- **WEG:** Wirtschaftsplan and Jahresabrechnung (para 28 WEG) by MEA or other keys, per sub-community
- **Facility management:** maintenance plan with legal basis and due dates, tickets, assets,
  meters and readings, expected recurring invoices, dashboard
- **Documents:** uploads per record; Posteingang fed from Mayan EDMS; Mayan full-text search
  inside the HV search (via a local bridge, the Mayan token stays on the Mayan host)
- **Security:** login with lockout after 3 wrong passwords, CSRF tokens, fail2ban jail, LAN/VPN-only
  Apache alias

## Demo data
`sql/sample.sql` (generated by `tools/make_sample.py`) is a small, entirely fictional data set:
Musterstraße 1 + 1a, 12345 Musterstadt – 2 houses, 6 flats, 3 parking spaces, 4 WEG units, tenants with
rents, charges and payments 2025 (one tenant change with vacancy, one tenant in arrears), expenses 2025,
heat cost allocators and water meters with readings, the heating costs set to the own HeizkostenV
calculation (CO2 stage, hot water share by heat meter), maintenance plan, tickets, WEG budget 2026.
Login `demo` / `demo`. Loading it deletes all existing data in the database.

## Layout
```
public/      web root (index.php front controller, assets: Bootstrap 5.3.3, Bootstrap Icons 1.11.3)
pages/       one file per page (?p=<name>); list.php / edit.php are generic CRUD driven by lib/entities.php
lib/         core (DB, helpers), entities, layout, calc (charges, WEG), bk (BetrKV/HeizkostenV), bank, mayan
sql/         schema.sql, schema_migrations.sql, sample.sql (fictional demo data)
tools/       importers (legacy controlling reports, Brunata meters, bank CSV), demo data, Mayan inbox + bridge,
             mayan_host/ helper for the Mayan server
deploy/      Apache conf, systemd unit, fail2ban filter/jail, logrotate
data/        runtime data, not in git (my.cnf, config.ini, uploads, inbox, bridge.key, imports)
```

## Install (Debian/Ubuntu)
```sh
# code to /srv/hausverwaltung, group www-data
mariadb -e "CREATE DATABASE hausverwaltung CHARACTER SET utf8mb4; CREATE USER 'hv'@'localhost' IDENTIFIED BY '...'; GRANT ALL ON hausverwaltung.* TO 'hv'@'localhost'"
printf '[client]\nuser=hv\npassword=...\ndatabase=hausverwaltung\n' > data/my.cnf; chmod 640 data/my.cnf
mariadb --defaults-file=data/my.cnf < sql/schema.sql
mariadb --defaults-file=data/my.cnf < sql/schema_migrations.sql
mariadb --defaults-file=data/my.cnf < sql/sample.sql      # fictional demo data, login demo / demo
cp deploy/hv.conf /etc/apache2/conf-available/ && a2enconf hv && systemctl reload apache2
# then change the demo password (Benutzer page) or create your own users there
```
Optional Mayan EDMS integration: `data/config.ini` with `[mayan] ssh_host=user@host` and `root_cabinet=<id>`,
`tools/mayan_host/hv_mayan.py` copied to `~/hv_mayan/` on the Mayan host (token in `~/.config/mayan_textbot_token`
there), `deploy/hv-mayan-bridge.service`, cron `*/15 * * * * php tools/mayan_inbox.php`.
fail2ban: `deploy/fail2ban-*`.
